## 解释边界

各任务冻结 backbone、各自训练 adapter 与任务头，当前证据针对任务适配能力；没有把任务一训练出的 adapter 冻结后跨任务转移，因此不直接证明可迁移的通用表征。dMaSIF checkpoint 的确切监督成员仍未核实，预训练重叠风险需随报告保留。任务二采用 DIPS bound 单体，任务三采用 AlphaFold 预测单体，跨任务的标签、分布与样本筛选也不同，不能单凭两项表现差异判定 bound/unbound 的因果作用。
